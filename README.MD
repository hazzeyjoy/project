YIDK – Youth Initiative Development

YIDK is a website designed to support a youth initiative focused on building confidence, opportunity, and a brighter future for young people.

About the Project

This project is a web-based platform created to present the initiative, its goals, activities, and opportunities for young people.

Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
